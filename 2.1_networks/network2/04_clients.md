
## 💻 4. PC Configuration (DHCP Clients)

### 4.1 Explanation  
Describe how you configured PCs to obtain addresses automatically.

Each PC was configured to obtain its IP address automatically by opening its Desktop tab, selecting IP Configuration, and switching the option from Static to DHCP. This allowed the PCs to dynamically receive their IP address, subnet mask, default gateway, and DNS server details from Server0
