
## 🧠 6. Reflection

Answer in full sentences:

1. What are the advantages of DHCP over static IP assignment?
DHCP automatically assigns IP addresses, which saves time on large networks and prevents human errors like duplicate IP address conflicts.

2. How does DNS improve usability in a network?
   DNS improves usability by allowing users to connect to devices using easy-to-remember hostnames instead of having to memorize complex numerical IP addresses.
   
3. What would happen if the DHCP server went offline?
If the DHCP server went offline, new devices joining the network would not be able to obtain an IP address, and existing devices would eventually lose network access once their current IP leases expired.
    
4. Optional: What part of this activity did you find easy or challenging? Why?
Setting up the physical network topology and enabling DHCP on the PCs was easy because it only required a few clicks, while configuring the server pools and DNS records required more careful attention to avoid typos in the IP addresses.
